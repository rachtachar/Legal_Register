# ระบบทะเบียนและประเมินความสอดคล้องของกฎหมาย (Legal Register & Compliance Web App)

ระบบเว็บแอปพลิเคชันสำหรับจัดการทะเบียนกฎหมาย ตรวจสอบการปฏิบัติตามกฎหมาย (Compliance Evaluation) และติดตามแผนแก้ไขข้อกำหนดที่ไม่สอดคล้องตามมาตรฐาน ISO 14001 / ISO 45001 พัฒนาต่อยอดจากโครงสร้างไฟล์ `Legal_Register.xlsx`

---

## ✨ ความสามารถของระบบ (Features)

1. **Dashboard สรุปภาพรวมและตัวชี้วัด (KPIs):**
   - การ์ดสรุป: กฎหมายที่ใช้อยู่, ข้อกำหนดทั้งหมด, % สอดคล้องล่าสุด (Compliance Rate), ข้อที่ต้องแก้ไข, ข้อที่เลยกำหนดแก้ไข (Overdue Alerts)
   - กราฟวงกลม (Donut Chart): สัดส่วนผลการประเมิน (สอดคล้อง / ไม่สอดคล้อง / ไม่เกี่ยวข้อง / ยังไม่ประเมิน)
   - กราฟแท่ง (Bar Chart): แนวโน้มการประเมินและจำนวนกฎหมายใหม่รายปี
   - สรุปความสอดคล้องแยกตามฝ่าย (Department Compliance: HR, IT, จป., ผลิต ฯลฯ)
   - **ตารางเตือนรายการเลยกำหนดแก้ไข (Action Required):** แสดงรายการที่พ้นกำหนดวัน Due Date พร้อมปุ่มอัปเดตผลประเมินทันที

2. **ทะเบียนกฎหมาย (Laws Register):**
   - เพิ่ม / แก้ไข / ลบ กฎหมาย
   - ค้นหากฎหมาย และกรองตามประเภท (พ.ร.บ., กฎกระทรวง, ประกาศ...) หรือสถานะ (ใช้อยู่, แก้ไข, ยกเลิก)
   - เชื่อมโยงลิงก์ราชกิจจานุเบกษา / ต้นฉบับ
   - แสดงจำนวนข้อกำหนดที่อยู่ภายใต้กฎหมายแต่ละฉบับ

3. **ข้อกำหนดกฎหมาย (Requirements Management):**
   - แตกข้อกำหนด/มาตราตามกฎหมายแต่ละฉบับ
   - ระบุฝ่ายที่รับผิดชอบ
   - แสดงผลประเมินล่าสุดและวันที่ประเมินแบบเรียลไทม์

4. **บันทึกการประเมินความสอดคล้อง (Assessments & Audits):**
   - ฟอร์มประเมินรอบใหม่: เลือกข้อกำหนด, วันที่, ผู้ประเมิน, ผลประเมิน
   - **Dynamic Action Plan:** หากเลือกผลเป็น "ไม่สอดคล้อง" ระบบจะบังคับให้ใส่ **แผนการแก้ไข (Action Plan)** และ **กำหนดแล้วเสร็จ (Due Date)**
   - บันทึกประวัติการตรวจประเมินย้อนหลัง (Audit Trail)
   - คำนวณสถานะ "เลยกำหนด" (Overdue) ให้อัตโนมัติเมื่อพ้นกำหนดวัน

5. **ประวัติการแก้ไข (Change Log):**
   - บันทึกประวัติการเปลี่ยนแปลงอัตโนมัติ (เพิ่ม/แก้ไข/ยกเลิกกฎหมายและข้อกำหนด)
   - มีปุ่มเพิ่มบันทึกช่วยจำ (Manual Note)

6. **การเชื่อมโยงกับ Excel:**
   - **Export to Excel:** ส่งออกฐานข้อมูลปัจจุบันเป็นไฟล์ Excel (.xlsx) ที่จัดรูปแบบสวยงาม
   - **Sync Excel:** ปุ่มรีโหลดข้อมูลตั้งต้นจาก `Legal_Register.xlsx` ได้ตลอดเวลา

## 🚀 วิธีเปิดใช้งานระบบ (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ Run
- ดับเบิลคลิกที่ไฟล์ **`run.bat`**
- ระบบจะเปิดเบราว์เซอร์ไปยัง `http://localhost:8000` โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Line
```bash
python app.py
```
เปิดเบราว์เซอร์ไปที่: **`http://localhost:8000`**

---

## 🛠 เทคโนโลยีที่ใช้
- **Backend:** Python, FastAPI, SQLite, Uvicorn, OpenPyXL
- **Frontend:** HTML5, Tailwind CSS, Lucide Icons, Chart.js, Vanilla JavaScript
- **Database:** SQLite (`legal_register.db` จัดเก็บไฟล์ในเครื่อง ไม่ต้องลง Database Server เพิ่มเติม)
